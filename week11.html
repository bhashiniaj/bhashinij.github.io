Phase 3: Hardware Implementation

Week 11: Boost Converter PCB Update

Arduino shield connection, sensing, protection, and layout finalization

Phase: Phase 3 — Hardware Implementation

Status: ✅ Completed

Author: Bhashini A.J. (E/21/060)

This Week's Changes

  • Switched the Arduino connection from loose wires to a shield-style plug-in design
  • Replaced the load resistor with battery connection pins
  • Added input voltage and current sensors for real-time monitoring
  • Added a zener diode to protect the feedback signal into the Arduino ADC
  • Planned physical clearance for heatsinks on the MOSFET and diode
  • Positioned all 4 Arduino header connectors using exact official coordinates
  • Finalized PCB layout zones and measured board dimensions

Arduino: Shield-Style Connection

Why: loose jumper wires near a 20 kHz switching signal can pick up noise and interfere with each other.

Fix: the PCB now plugs directly onto the Arduino, like a shield — short, fixed connections, with no loose wires. Four header connectors (Digital High – 10-pin, Digital Low – 8-pin, Analog In – 6-pin, Power – 8-pin) were placed at exact Arduino Uno spacing, then grouped and locked together as one unit so the relative spacing can't be disturbed.

Voltage & Current Sensing + Protection

New sensors added

  • Current sensor (ACS712) — inline between the PV panel and the inductor, feeding Arduino pin A2
  • Vin voltage sensor — divider tapping the PV input, feeding A1
  • Vout voltage sensor — existing R2/R3 divider, feeding A0

Protection added

  • 5.1 V zener diode placed between the Vout feedback line and GND
  • Clamps the signal into A0, protecting the Arduino's ADC from voltage spikes

Heatsinks & Component Clearance

  • Heatsinks needed on Q2 (IRF540N) and D1 (MBR10100CT) — both dissipate real power at switching frequency
  • Not a schematic component — purely a PCB layout and mechanical planning consideration
  • Kept 15–20 mm clearance between Q2 and D1, so clip-on heatsinks don't collide
  • Repositioned C1 (output capacitor) away from Q2 to avoid crowding the heatsink zone
  • Insulating thermal pads planned in case both heatsinks sit close together, since TO-220 tabs can be live

Building the Shield-Style Connector

  • Sourced the official Arduino Uno R3 Eagle CAD files for header pin coordinates
  • Placed 4 generic pin headers (Power, Analog In, Digital Low, Digital High) at the exact official spacing
  • Grouped and locked the 4 headers so relative spacing can't be accidentally disturbed
  • Result: the PCB plugs directly onto a real Arduino Uno, with no loose wiring needed

Reference template: github.com/LNSD/Arduino-Shield-Template

PCB Layout Dimensions

Board size: approx. 110 mm × 100 mm — sized to comfortably fit the power stage, gate drive, sensing, and header zones.
